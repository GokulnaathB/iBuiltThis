This is a [PRODUCT DISCOVERY SITE](https://i-built-this-eight.vercel.app/) built using [Next.js](https://nextjs.org), bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

Share What You've Built, Discover What's Launching: https://i-built-this-eight.vercel.app/

Tech stack used:

- TypeScript
- Next.js
- Clerk for auth
- Neon Postgres
- Drizzle ORM
- Zod
- Shadcn
- Tailwind
- Deployed on Vercel

Technical details:

- Built a responsive, full-stack product discovery site iBuiltThis, grants users to submit, explore, and vote projects.
- Developed using Next.js (App Router) with Server Components, Server Actions, and Caching.
- Implemented auth using Clerk, designed and managed database using Neon and Drizzle
- Integrated optimistic UI updates for voting using useOptimistic hook, improving perceived performance.
- Implemented admin moderation system and organization based access control.
